# MadnessCup 🏆

**MadnessCup** is a Minecraft multiplayer minigame project built with **Java and Paper**, designed around fast-paced team-based games and a flexible game management system.

The project started as a way to explore Minecraft server development and has grown into a larger software project involving **game logic, player and team management, asynchronous tasks, REST APIs, and backend development**.

## 🎮 What is MadnessCup?

MadnessCup is designed to bring multiple competitive minigames together under one Minecraft server.

Players can join queues, form teams, and participate in different games, with the plugin handling the underlying game state, player interactions and team management.

The project is being developed with an emphasis on creating a clean and reusable foundation that can be extended with new games and features over time.

### Current Features

* 🏆 Team-based game management
* 👥 Player queues and matchmaking
* 🎨 Team management and customisation
* 📋 Interactive Minecraft inventory menus
* ⏱️ Game countdowns and scheduled tasks
* 🔧 Administrative tools and controls
* 🌐 Communication between the Minecraft server and a backend service
* 📡 REST API integration using Spring Boot
* 📦 JSON-based data exchange using Gson
* 🧩 Modular game components designed to support additional minigames

## 📚 Why I Built It

I created MadnessCup to combine my interest in **software development and Minecraft** while working on a project large enough to explore concepts beyond university coursework.

Rather than building a single small plugin, I wanted to develop a system where different components could interact and where new functionality could be added without having to redesign the entire project.

The project has also given me the opportunity to experiment with technologies such as **Spring Boot and REST APIs**, alongside the Java and object-oriented programming skills I use throughout the plugin.
